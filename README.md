# Áudios Mulher Conectada
**by Catiana A. Oliveira**

Plataforma web de áudios de desenvolvimento pessoal, ativações vibracionais, afirmações e práticas psicossomáticas com visual clean em tons rosa pastel, suporte a modo repetição contínua (loop) e acompanhamento de letra sincronizada estilo Spotify.

## ✨ Recursos

- **Design Responsivo & Elegante:** Paleta rosa pastel suave com efeito glassmorphism e tipografia refinada (*Cormorant Garamond* e *Montserrat*).
- **Categorias no Menu:**
  - ✦ Todos os Áudios
  - ☀️ Despertar Matinal
  - 🌿 Corpo & Psicossomática (Práticas exclusivas com direcionamento para compra)
  - 🌙 Noite & Sono
- **Player de Áudio Completo:**
  - Controle de reprodução e barra de progresso interativa.
  - Botão de repetição (Loop) individual.
  - Letra sincronizada em tempo real (destaque dinâmico e clique para saltar para o trecho do áudio).
- **Leve e Rápido:** Construído em HTML5, CSS3 e JavaScript puro, sem dependências pesadas, ideal para GitHub Pages.

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório no [GitHub](https://github.com).
2. No seu terminal nesta pasta, execute:
   ```bash
   git init
   git add .
   git commit -m "feat: lancamento audios mulher conectada"
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   git push -u origin main
   ```
3. No GitHub, acesse **Settings** > **Pages** do repositório.
4. Em **Build and deployment** / **Branch**, selecione `main` e a pasta `/ (root)`.
5. Clique em **Save**. Em instantes seu site estará online gratuitamente!
